--部署好后，需要部署 VMPodScrape 收集指标-- 此脚本已经放在了 helm chart 包中了 

```
apiVersion: operator.victoriametrics.com/v1beta1
kind: VMPodScrape
metadata:
  name: koordlet-metrics
  namespace: monitoring-system
spec:
  namespaceSelector:
    any: true
  podMetricsEndpoints:
  - interval: 30s
    path: /metrics
    targetPort: 9316
  selector:
    matchLabels:
      koord-app: koordlet
```
